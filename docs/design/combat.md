# 战斗数值设计

> 本目录存放设计侧文档（数值表、关卡设计等），供远程查阅与调整。
> **可执行真值在 `src/level-config.ts`**：`COMBAT` 是游戏实际读取的常量。
> 两者必须同步修改——改表必改码，改码必改表。

## 前提（precondition）

- 所有单位生命统一为 **100 点池**（`COMBAT.unitHealth`）
- 一切伤害以**受击方最大生命池的百分比**表示，与攻击方是谁无关地归一
- 未来新单位（Boss、修复单位等）沿用同一池语义：Boss 可以是 300 = 3 个池，
  格子语义不变，表格自动泛化

## 伤害矩阵

行 = 攻击方，列 = 受击方，格 = 单发伤害占受击方池的百分比。

### pirate-to-defender（海盗 → 守方）

| atk/hurt | cannon（城防炮） | ballista(防空弩) |
|:--------:|:----------------:|:-------------:|
| ship     | 15%              | 17.5%         |
| bombardier | 10%            | 15%           |

### defender-to-pirate（守方 → 海盗）

| atk/hurt | ship（海盗船） | bombardier(投弹飞行器) |
|:--------:|:--------------:|:-------------------:|
| cannon   | 20%            | 25%                |
| ballista | 10%            | 20%                |

未知组合（表中未写的格）视为 0——打不动的目标显式写 0%，
免疫关系（如将来城墙免疫船炮）不靠缺省猜。

## 当前节拍（由表推导，改表后重算）

- 城防炮沉一艘船：ceil(100 / 20) = **5 发**；单炮理论 12.5–15s（含抖动）
- 一艘海盗毁一门炮：ceil(100 / 15) = **7 发**；单船 18–21s（3s 间隔）
- 结论：单挑城防炮占优，压力来自多船齐压下的火力分配
- 城防炮击落一架飞行器：ceil(100 / 25) = **4 发**；单炮理论 10–12s（含抖动）
- 防空弩击落一架飞行器：ceil(100 / 20) = **5 发**；1.5s + 抖动 ≈ 1.7–2.0s/发，直射弹道需玩家手动瞄准
- 飞行器毁一门炮：ceil(100 / 10) = **10 发**；毁一架弩：ceil(100 / 15) ≈ **7 发**（2s 间隔）
- 海盗船毁一架弩：ceil(100 / 17.5) = **6 发**（3s 间隔）
- 防空弩对船（10%）为休眠格：60–75° 仰角的直射弹不会落到水面
- 弩箭：程序化弩箭 glb（顶点色、粗糙度 0.5），沿炮管朝向直射无重力，越过 y=3.25 静默回收；命中闪光/碎裂沿用统一特效
- 投弹飞行器：与海盗船同一套目标选择/闭式必中投弹，区别在于无炮塔节点——整机绕 y 轴转向目标，越过自身远停线（z≥-1.80）即获开火许可

## 扩展约定

- 新攻击方 → 加一行；新受击方 → 加一列；Boss 单独成行/列即可
- 引入护甲/弱点概念时，格子改为「基础百分比 × 目标倍率」两层，
  基础表保持不变
- 修复/再生与伤害同货币：每秒 +N%（N 为池的百分比），进表时单列一节
