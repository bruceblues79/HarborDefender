# 战斗数值设计

> 本目录存放设计侧文档（数值表、关卡设计等），供远程查阅与调整。
> **可执行真值在 `src/level-config.ts`**：`COMBAT` 是游戏实际读取的常量。
> 两者必须同步修改——改表必改码，改码必改表。

## 前提（precondition）

- 所有单位生命统一为 **100 点池**（`COMBAT.unitHealth`）
- 一切伤害以**受击方最大生命池的百分比**表示，与攻击方是谁无关地归一
- 未来新单位（Boss、修复单位等）沿用同一池语义：Boss 可以是 300 = 3 个池，
  格子语义不变，表格自动泛化

## 伤害矩阵

行 = 攻击方，列 = 受击方，格 = 单发伤害占受击方池的百分比。

### pirate-to-defender（海盗 → 守方）

| atk/hurt | cannon（城防炮） | ballista(防空弩) |
|:--------:|:----------------:|:-------------:|
| ship     | 15%              | 17.5%         |
| bombardier | 10%            | 12.5%           |

### defender-to-pirate（守方 → 海盗）

| atk/hurt | ship（海盗船） | bombardier(投弹飞行器) |
|:--------:|:--------------:|:-------------------:|
| cannon   | 20%            | 25%                |
| ballista | 10%            | 20%                |

未知组合（表中未写的格）视为 0——打不动的目标显式写 0%，
免疫关系（如将来城墙免疫船炮）不靠缺省猜。

## 经济系统（economy）

金钱是建造与修理的唯一货币，真值在 `ECONOMY`（`src/level-config.ts`）。

| 语义 | level-config.ts 常量 | 当前值 |
|---|---|---|
| 每局起始金钱（START / RESTART 均重置） | `ECONOMY.startMoney` | 200 |
| 击毁奖励（敌方单位死亡瞬间入账，统一价） | `ECONOMY.killReward` | 200 |
| 修理回血速度（每秒） | `ECONOMY.repairHpPerSecond` | 10 |
| 修理扣钱速度（每秒，回血期间持续扣） | `ECONOMY.repairCostPerSecond` | 8 |
| 换防折扣（存活旧单位账面价值 × 折扣 = 抵扣额） | `ECONOMY.replaceDiscount` | 0.3 |
| 守方单位账面价值（唯一计价：新建全价 = 换防折价基数，见下节） | `ECONOMY.unitValues` | cannon / sky-ballista 均 200 |

规则：

- 修理由玩家通过城防单位旁的**扳手按钮**开关：持续回血 + 持续扣钱，
  血满 / 钱尽 / 单位被毁任一条件终止；修理中扳手呼吸高亮
- 建设通过**锤子按钮**打开共享建设面板：选中目标单位换上；
  空位或已毁槽位按账面价值**全价新建**（200）；槽内单位存活时按
  **补差价**结算：「新单位账面价值 − 旧单位账面价值 × 3 折」
  （账面统一 200 → 200 − 60 = **140，双向同价**）

## 击毁价值（bounty，收入侧）

击毁奖励是金钱的唯一收入来源，起始金只是初始资本。

| 敌方单位 | unitType | 击毁奖励 |
|:--------:|:--------:|:--------:|
| 海盗船 | `pirate-ship` | **200g** |
| 投弹飞行器 | `bombardier` | **200g** |

- 当前为**统一价**：所有敌方目标击毁均奖励 200g（设计定值，姑且承认）
- 奖励入全局钱包（`Wallet`，挂在 director 实体上），不区分击毁者是谁，
  在敌方单位被判定死亡的瞬间一次性入账（`ShellHitSystem` 死亡分支）；
  残血、逃跑、波次结束均不清算
- 新敌方单位加入时默认沿用统一价；需要差异化（如 Boss 高赏金）时再拆成
  per-unit 列，表结构不变
- 入账落点：`ShellHitSystem` 攻击方死亡分支 → `Wallet.money +=
  ECONOMY.killReward`（映射见上方经济表）；暂停期间不入账（系统整帧
  early-return），GameOver 后火炮静默、不再产生击杀

## 我方单位价值（账面，暂定）

守方单位的账面价值，与敌方赏金对称，暂定统一 200g。

| 守方单位 | unitId | 账面价值 |
|:--------:|:------:|:--------:|
| 城防炮 | `cannon` | **200g** |
| 防空弩 | `sky-ballista` | **200g** |

- 账面价值是**唯一计价**：新建全价 200，换防补差价 140；原建造价
  （80/120）已退役删除——否则换防 140 会比空位新建 120 还贵，
  折旧抵扣反而变成加价
- 消费方已接线：`ECONOMY.unitValues` + `replaceDiscount`，映射见上方
  经济表

## 当前节拍（由表推导，改表后重算）

- 城防炮沉一艘船：ceil(100 / 20) = **5 发**；单炮理论 12.5–15s（含抖动）
- 一艘海盗毁一门炮：ceil(100 / 15) = **7 发**；单船 18–21s（3s 间隔）
- 结论：单挑城防炮占优，压力来自多船齐压下的火力分配
- 城防炮击落一架飞行器：ceil(100 / 25) = **4 发**；单炮理论 10–12s（含抖动）
- 防空弩击落一架飞行器：ceil(100 / 20) = **5 发**；1.5s + 抖动 ≈ 1.7–2.0s/发，直射弹道需玩家手动瞄准
- 飞行器毁一门炮：ceil(100 / 10) = **10 发**；毁一架弩：ceil(100 / 12.5) = **8 发**（2s 间隔）
- 海盗船毁一架弩：ceil(100 / 17.5) = **6 发**（3s 间隔）
- 防空弩对船（10%）为休眠格：60–75° 仰角的直射弹不会落到水面
- 弩箭：程序化弩箭 glb（顶点色、粗糙度 0.5），沿炮管朝向直射无重力，越过 y=3.25 静默回收；命中闪光/碎裂沿用统一特效
- 投弹飞行器：与海盗船同一套目标选择/闭式必中投弹，区别在于无炮塔节点——整机绕 y 轴转向目标，越过自身远停线（z≥-1.80）即获开火许可

## 扩展约定

- 新攻击方 → 加一行；新受击方 → 加一列；Boss 单独成行/列即可
- 引入护甲/弱点概念时，格子改为「基础百分比 × 目标倍率」两层，
  基础表保持不变
- 修复/再生与伤害同货币：每秒 +N%（N 为池的百分比），进表时单列一节
